FashionOasis is a simple e-commerce web-based platform for showcasing fashion products, built with PHP, MySQL, HTML, CSS, and JavaScript.

Features:
- User registration and login system
- Sample product listings, details, and checkout forms
- Contact form for customer feedback
- Store location and contact details
- Embedded Google Maps for store location
- Responsive navigation and layout

Prerequisites
- XAMPP (recommended) or any local PHP/MySQL server
- Git (optional, for version control)

Installation
- Clone or download the repository to your htdocs directory under xampp folder:
- Open your XAMPP and start your Apache and SQL.
- Go to http://localhost/phpmyadmin and import the samp.sql file into your MySQL database.
- Update database connection settings in your PHP files as needed.
- Access the project at http://localhost/FashionOasis/index.html in your browser.

Database
- The database structure is provided in samp.sql.
